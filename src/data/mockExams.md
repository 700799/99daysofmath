## Section A: Multiplication & Division Fluency (40 points)

**Problem 1: Multi-digit multiplication** *(10 points)*
```
3,456 × 7 = ?
```
**Solution:**
```
  3,456
×     7
-------
 24,192

• Start with ones: 6 × 7 = 42 (write 2, carry 4)
• Tens: 5 × 7 = 35, plus carry 4 = 39 (write 9, carry 3)
• Hundreds: 4 × 7 = 28, plus carry 3 = 31 (write 1, carry 3)
• Thousands: 3 × 7 = 21, plus carry 3 = 24 (write 24)

Answer: 24,192
```
**Course Alignment:** Course 1 (foundational fluency)  
**Common Mistake:** Students forget to carry or place digits incorrectly

## Section B: Word Problems (40 points)

**Problem 5: Multi-step word problem** *(20 points)*
```
A school has 245 students. Each classroom holds 28 students.
How many classrooms are needed?
```
**Solution:**
```
Step 1: Identify what we know
   • Total students: 245
   • Students per classroom: 28
   
Step 2: Identify what we're looking for
   • How many classrooms needed?
   
Step 3: Set up the math
   • We need to DIVIDE total by classroom size
   • 245 ÷ 28 = ?
   
Step 4: Calculate
     8
   ____
28 | 245
    224 (28 × 8)
    ---
     21

   • 28 goes into 245 eight times (28 × 8 = 224)
   • Remainder: 245 - 224 = 21
   • Since there are 21 students left over, we need ONE MORE classroom
   
Step 5: Answer with context
   • 8 classrooms would hold 8 × 28 = 224 students
   • We have 21 students left, so we need 1 more
   
Answer: 9 classrooms

(Note: This is a REAL-WORLD remainder problem. We can't have 0.75 classrooms!)
```
**Course Alignment:** Course 2 (interpreting remainders in context)  
**Common Mistake:** Students say "8 with remainder 21" without thinking about what that means

## Section C: Fractions (20 points)

**Problem 7: Fraction subtraction with unlike denominators** *(10 points)*
```
3/4 − 1/6 = ?
```
**Solution:**
```
Step 1: Find a common denominator
   • Denominators: 4 and 6
   • LCM(4,6) = 12
   
Step 2: Convert to equivalent fractions with denominator 12
   • 3/4 = (3×3)/(4×3) = 9/12
   • 1/6 = (1×2)/(6×2) = 2/12
   
Step 3: Subtract
   • 9/12 - 2/12 = 7/12
   
Step 4: Check if simplifiable
   • GCD(7, 12) = 1, so 7/12 is already in simplest form

Answer: 7/12
```
**Course Alignment:** Course 1 (fraction operations)  
**Common Mistake:** Students subtract without finding common denominator (3/4 - 1/6 ≠ 2/2)

---

**Problem 8: Convert decimal to fraction** *(10 points)*
```
Convert 0.375 into a fraction in simplest form.
```
**Solution:**
```
Step 1: Write as a fraction with a power of 10 denominator
   • 0.375 has 3 decimal places
   • So: 0.375 = 375/1000
   
Step 2: Simplify by finding GCF
   • Find GCF(375, 1000)
   • 375 = 3 × 125 = 3 × 5³
   • 1000 = 8 × 125 = 2³ × 5³
   • GCF = 125
   
Step 3: Divide both numerator and denominator by GCF
   • 375 ÷ 125 = 3
   • 1000 ÷ 125 = 8
   • So: 375/1000 = 3/8
   
Step 4: Verify
   • 3 ÷ 8 = 0.375 ✓

Answer: 3/8
```
**Course Alignment:** Course 2 (converting forms; understanding equivalence)  
**Common Mistake:** Students don't simplify and leave answer as 375/1000

**Possible Solution (Gauss-like pattern recognition):**

Another approach: Doubling strategy

# EXAM 2: RATIOS & EXPRESSIONS
**Time: 45 minutes | Total: 100 points**

## Section A: Ratios & Rates (30 points)

**Problem 1: Simplify a ratio** *(10 points)*
```
Simplify the ratio 12 apples to 8 oranges.
```
**Solution:**
```
Step 1: Write the ratio
   • 12 : 8
   
Step 2: Find GCF of 12 and 8
   • 12 = 2² × 3
   • 8 = 2³
   • GCF(12, 8) = 4
   
Step 3: Divide both by GCF
   • 12 ÷ 4 = 3
   • 8 ÷ 4 = 2
   
Step 4: Write simplified ratio
   • 3 : 2
   
Verification: 3/2 = 1.5, and 12/8 = 1.5 ✓

Answer: 3:2 (or 3 to 2)
```
**Course Alignment:** Course 1 (ratio simplification)  
**Common Mistake:** Students only divide one number (12÷4, but forget to divide 8)

---

**Problem 2: Unit rate** *(10 points)*
```
If 3 notebooks cost $6, what is the unit rate?
```
**Solution:**
```
Step 1: Identify what we know
   • Total cost: $6
   • Number of notebooks: 3
   
Step 2: Find unit rate (cost per notebook)
   • Cost per notebook = Total cost ÷ Number
   • = $6 ÷ 3
   • = $2 per notebook
   
Step 3: Verify
   • If 1 notebook costs $2, then 3 cost 3 × $2 = $6 ✓

Answer: $2 per notebook
```
**Course Alignment:** Course 1 (unit rates; division concept)  
**Common Mistake:** Students calculate 3÷6 instead of 6÷3

**Solution:**
```

Step 3: Write as expression
   • (3 × $4.50) - $5 = $8.50
   
Step 4: Verify
   • Without coupon: $13.50
   • With $5 off: $13.50 - $5 = $8.50 ✓

**Problem 10: Write and solve an equation** *(7.5 points)*
```
Write an expression:
"5 more than twice a number."
Then solve if the expression equals 21.
```
**Solution:**
```
Step 1: Define the variable
   • Let x = the number
   
Step 2: Translate "5 more than twice a number"
   • Twice a number = 2x
   • 5 more than = + 5
   • Expression: 2x + 5
   
Step 3: Solve if expression equals 21
   2x + 5 = 21
   2x + 5 - 5 = 21 - 5  (subtract 5 from both sides)
   2x = 16
   2x ÷ 2 = 16 ÷ 2     (divide both sides by 2)
   x = 8
   
Step 4: Check
   • Twice 8 = 16
   • 5 more than 16 = 21 ✓

Answer: Expression is 2x + 5; the number is 8
```
**Course Alignment:** Course 3 (algebra; multi-step equations)  
**Common Mistake:** Students write 5 + 2 + x or forget order of operations

```

```

```

**Problem 6: Probability of an event** *(7.5 points)*
```
A bag has 3 red, 2 blue, 5 green marbles.
What is P(red)?
```
**Solution:**
```
Definition: Probability = (Number of favorable outcomes) / (Total outcomes)

Step 1: Count favorable outcomes (red marbles)
   • Red marbles = 3
   
Step 2: Count total outcomes (all marbles)
   • Total = 3 + 2 + 5 = 10
   
Step 3: Calculate probability

```

## Section E: Challenge & Multi-Step (20 points)

**Problem 11: Perimeter & algebra** *(10 points)*
```
A rectangle has perimeter 50.
Length is 15. Find the width.
```
**Solution:**
```
Formula: Perimeter = 2(length + width)

Step 1: Set up equation
   50 = 2(15 + w)
   
Step 2: Divide both sides by 2
   50 ÷ 2 = 15 + w
   25 = 15 + w
   
Step 3: Solve for w
   25 - 15 = w
   w = 10
   
Step 4: Check
   Perimeter = 2(15 + 10) = 2(25) = 50 ✓

Answer: Width = 10
```
**Course Alignment:** Course 2 (multi-step equations with context)  
**Common Mistake:** Students forget the factor of 2 in perimeter formula

**Problem 12: Average / Mean problem** *(10 points)*
```
A student scores 85, 90, 95 on three tests.
What score is needed on the 4th test to average 90?
```
**Solution:**
```
Step 1: Set up equation
   • Average = (Sum of scores) / (Number of tests)
   • Let x = 4th test score
   • 90 = (85 + 90 + 95 + x) / 4
   
Step 2: Simplify
   90 = (270 + x) / 4
   
Step 3: Multiply both sides by 4
   90 × 4 = 270 + x
   360 = 270 + x
   
Step 4: Solve for x
   x = 360 - 270
   x = 90
   
Step 5: Check
   • Average = (85 + 90 + 95 + 90) / 4 = 360 / 4 = 90 ✓

Answer: 90 (ironically, needs exactly the average!)
```
**Course Alignment:** Course 3 (algebra + statistics)  
**Common Mistake:** Students only add the three scores and divide by 3

# STUDENT TIPS FOR SUCCESS

1. **Read problems twice** — Once to understand, once to identify what you need to find
2. **Show all work** — Even if you know the answer, write the steps. It helps you catch mistakes.
3. **Check your answer** — Plug it back into the original problem. Does it work?
4. **Use estimation** — Rough estimates catch wild errors (like saying 3,456 × 7 = 241,920)
5. **Remember PEMDAS** — Parentheses, Exponents, Multiply/Divide, Add/Subtract
6. **Understand word problems** — Circle important numbers. Underline the question. Ignore distractors.
7. **Know your times tables** — Speed matters. Drill 7 × 8, 9 × 6, etc. daily.
8. **Decimals & fractions are cousins** — They're the same concept; learn both forms.

---

# PRACTICE TIPS FOR PARENTS

- **Week 1-2:** Drill multiplication & division facts. Speed is important (aim for <5 sec per problem).
- **Week 3:** Practice ratios with real items (4 apples vs 6 oranges). Make it visual.
- **Week 4:** Have kids write equations from English sentences ("I have 5 more than you").
- **Week 5:** Use geometry in the house (measure room areas, calculate box volumes).
- **Week 6:** Play games involving probability (dice, card decks, marble draws).
